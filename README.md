# Simple Dashboard UI Task Management & Post (Test Y Ventures)

Developed by Anugerah Prima Bagaskara

## Features

1. Task Management /tasks
2. Posts /posts

## Tech Stack

1. Framework: React
2. Language: TypeScript
3. Styling: Tailwind CSS & Ant Design
4. State Management: Redux Toolkit
5. Data Fetching: TanStack Query & Axios
6. Testing: Vitest

```bash
Vitest is used instead of Jest due to compatibility issues between Jest and Vite.
Reference: https://jestjs.io/docs/getting-started
```

7. Build Tool: Vite

## Installation

1. Clone this repository
2. Open the project directory
3. `npm install`
4. `npm run dev`
